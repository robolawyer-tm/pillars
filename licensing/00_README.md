# Licensing — the split

Code is AGPL-3.0 with copyright kept, writing and public inferences are CC BY 4.0, and the private store and anyone else's material get no licence from us.

- Decided by John 2026-11-27 after GESIS approved pairfam/FReDA access ("we may be known now"); this record states the split, 10_APPLY.md says where each part lands
- Code (scripts, operators, site code, tools): AGPL-3.0-or-later; anyone may run, change and share it, and changes must be shared even when served over a network
- Copyright on the code stays with John, which keeps a later commercial licence beside AGPL possible (dual licensing)
- Dual licensing holds only while John owns every line: an outside contribution is accepted only with a contributor licence agreement (CLA) signed first
- Writing (docs, blog, methods report, preprint, findings once John makes them public): CC BY 4.0; reuse of any kind, credit required
- Public inferences (the files already tracked in public repos, e.g. vivify-operators/inferences/): CC BY 4.0, the same as writing
- The private store (~/private_field) is never published, so no licence applies; it stays all rights reserved, and it is the asset, not the code
- Third-party text is excluded from every licence above: the raw_text fields of the five field inferences (Innocence Project case text), case readings quoting it, and the NYC open data in the lescc fork
- Data-derived aggregates (tables from pairfam, FReDA, Add Health, FFCWS, NLSCYA, StatCan): our tables take CC BY 4.0 only where the source's terms allow it, and the source's terms always come first
- pairfam/FReDA terms bind from the GESIS contract (still to arrive): aggregates only, no microdata, cells under 10 suppressed, dataset citation; the contract is read before any pairfam table goes out
- Each other source's citation and reuse terms get checked and written into 20_SOURCES.md before its first public table; until then, none is assumed
- Names are not licensed: "Dimensional Fields", "Robolawyer" and "robolawyer-tm" stay John's; AGPL and CC BY grant no trademark rights
- secret-server keeps its public-domain dedication: shipped versions cannot be taken back, and leaving it alone costs nothing
- CC BY and AGPL grants are permanent for every version shipped under them; a later change binds only later versions
- The current site footer ("Copyleft … free to share and remix without restrictions" plus "©") contradicts itself and is replaced by a plain notice of the split
- AI-written code and text may carry weaker copyright than human-written, especially in the US; that weakens enforcement and dual licensing for those parts, not the grants to users
- This record is a working plan, not legal advice; a lawyer's review is worth it before a commercial licence is sold or a CLA is signed
